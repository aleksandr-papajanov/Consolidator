# Ревью и исправление изменений

Результат — исправленный код с сохранённой целью изменения. Применять по запросу
ревью/исправлений уже написанного кода, не как обязательный финал каждой реализации.

1. Прочитать [AGENTS.md](../../../AGENTS.md) и пройти его порядок чтения документации
   для решения и затронутых проектов. Требования брать из Docs владельцев.
2. Определить доступный состав изменения: staged, unstaged, untracked, новые файлы
   и документацию. Явный запрос просмотра незакоммиченных Git-изменений разрешает
   их read-only просмотр. Без такого разрешения использовать переданный/editor diff
   и прямое чтение, указав неполноту обзора. Не менять Git state.
3. Восстановить намерение: какие наблюдаемые сценарии и контракты должны измениться.
   Разбирать по поведению, не только по файлам. Отметить затронутых владельцев и
   проследить callers, данные и lifecycle за пределы diff, где это нужно для причины.
4. Сопоставить реализацию с контрактами этих scope. Особое внимание уделить местам,
   где обязанность пересекла границу проекта, изменение применяется частично,
   запоздалый результат меняет новый target или callback переживает владельца.
   При переносе ответственности перевести callers и удалить заменённый путь,
   сохранив пользовательский результат.
5. Исправлять установленные причины, затем повторно читать полный затронутый путь
   и последствия исправления. Не останавливаться на списке замечаний. Для спорного
   поведения уточнить только неоднозначный контракт, продолжая независимую работу.
6. Обновить документы владельцев при изменении контракта. Прочитать итоговую правку
   вместе с её callers: исходный дефект устранён, новый обходной путь не появился.
   Разрешённые проверки выбирать по [Testing](../../../Docs/Aspects/Testing.md)
   и документам затронутого scope; наличие skill не выдаёт разрешений на их запуск.

В результате сообщить исправленные дефекты и последствия, оставшиеся проблемы с
причинами, реальные проверки и их ограничения. Не выдавать предпочтение стиля за
ошибку и не выполнять несвязанную переработку ради единообразия.
