# Raw Audio

Recordings содержит5 оригинальных пользовательских записей; Probes — набор уникальных
необработанных входных сигнала: isolated/paired hits, level-scaled copies, impulses
и tone steps. Они пригодны для будущих ручных исследований других устройств.
Processed reference/candidate audio сюда не входит. Дубликаты удалены по SHA256.

[catalog.json](catalog.json) содержит путь, тип, размер, checksum и происхождение.
Original — provenance: старые experiment paths могли быть удалены.
Оригинальные Desktop recordings оставлены на месте.
Raw не нормализовать и не перезаписывать: результаты опыта писать отдельно.
[Как пользоваться EmulationLab](../../Docs/Dsp/EmulationLab.md).

CLA-76 ALL: Probes/cla76-all-9986-level-dependencies.wav содержит56 секунд
переходов -20/0, -32/-12, -8/0 и -40/-20 dBFS; каждый участок5/4/5 секунд.
Probes/cla76-all-9986-cold-repeated.wav содержит24 секунды cold/repeated переходов,
начиная с1/2/1 секунды -20/0/-20 dBFS. Оба сигнала —998.6 Hz, stereo44.1 kHz.

CLA-3A: Probes/cla3a-9986-doctor-steps.wav содержит четыре пары1/2/1 секунды
с теми же уровнями и4 секунды тишины. Это20 секунд непрерывной фазы,
998.6 Hz/stereo44.1 kHz, для сравнения короткой истории компрессии.

Probes/cla3a-592-doctor-steps.wav повторяет эту последовательность на 59.2 Hz
для исследования баса. Это сырой стереосигнал с непрерывной фазой, без обработки.

Probes/cla3a-pump-probe-199.wav содержит 199 Hz pump и четыре тихие пробы
997/6001/12007/15587 Hz. Pump выключен либо имеет уровень -40/-30/-20/-10/-0.1 dBFS;
вся последовательность повторяется с пробами -60 и -66 dBFS. Каждый участок8 секунд,
общая длина96 секунд, stereo44.1 kHz. Это сырой сигнал для исследования частотного
ослабления при общей компрессии; обработанные рендеры сохраняются в Experiments.

Probes/processor-simplification-44100.wav и processor-simplification-96000.wav —
24-секундные stereo float probes для сравнения законченных моделей. Частоты
60/120/1000/12000 Гц; на каждой уровни−30/−18/−12/−6/0/+6 dBFS, по1 секунде.
Края сегментов имеют5 мс fade, правый канал0.8 от левого с фазовым сдвигом0.3 rad.
Файлы не содержат обработку моделей и сохранены для будущих исследований.

CLA-2A: Probes/cla2a-level-timing-colour.wav — 103 секунды stereo float32, 44.1 kHz.
Четыре истории уровня по 5/4/5 секунд на 998.6 Hz, семь установившихся уровней
от −48 до 0 dBFS и тихие тоны от 8 Hz до 20 kHz. Фаза непрерывная; переходы
уровня не сглажены. Это необработанный вход для исследования компрессии и АЧХ.

Probes/cla2a-short-repeated-9986.wav — 36 секунд stereo float32, 44.1 kHz.
Три цикла 1/2/1 секунды −20/0/−20 dBFS на 998.6 Hz, затем шесть 4-секундных
уровней от −48 до 0 dBFS. Непрерывная фаза позволяет сравнить первый запуск
и накопление компрессии в следующих циклах при одинаковых настройках ручек.

SSLChannel raw probe: `Probes/ssl-channel-level-timing.wav`, 86 seconds at 44.1 kHz,
stationary 998.6 Hz levels, three long step histories, and frequency pairs.
