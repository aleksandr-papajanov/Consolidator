# SaturationProcessor

[Исходник](../../External/Dsp/SaturationProcessor.cpp).

Связанный максимум sidechain создаёт нормализацию через 500 мс energy follower с компенсацией веса начального окна.

Для нормализованного x: k=0.75+1.25*Curve; Shape(x)=sqrt(1+k²)*x/sqrt(1+k²*x²).

Drive смешивает нелинейный остаток с dry; Drive0 — identity.

First-order ADAA интегрирует Shape(x)-x между соседними физическими отсчётами, с рационализированной разностью антипроизводной.

Оба конца используют текущие параметры и нормализацию.

Split — комплементарные low/mid/high при 250/2500 Гц; одинаковая кривая для каждой полосы, full/split переход 10 мс.

Истории фильтров и предыдущих samples продвигаются даже в неслышимой ветке.

Частичная RMS autogain масштабируется Drive.

Это не brick-wall limiter и не alias-free обработка.
